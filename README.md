# Handwritten Character Recognition (CNN)

## 📌 Objective
Identify handwritten alphabets using deep learning.

## ⚙️ Approach
- Image Processing using OpenCV
- Deep Learning using CNN

## 📊 Dataset
- EMNIST (Extended MNIST)

## 🧠 Model
- Convolutional Neural Network (CNN)

## 🚀 Features
- Detect handwritten letters
- Convert letters into words
- Image → Text prediction

## 🔮 Future Scope
- Sentence recognition using CRNN
- GUI for real-time prediction

## ▶️ How to Run

Train:
py train_cnn.py

predict:
py predict_cnn.py
